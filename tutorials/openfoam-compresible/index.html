OpenFOAM · Compressible flow

A tutorial series on compressible flow with OpenFOAM: shock and expansion waves whose theory is known, so that every case can be checked number by number. Each tutorial brings the complete case, the mesh from Gmsh, and a validation against theory with a mesh-convergence study.

On Windows, with blueCFD-Core. Every figure and number comes from an actual run of OpenFOAM 12 in blueCFD-Core 2024, with Gmsh 4.15.2 and ParaView 5.11.2.

Una serie sobre flujo compresible con OpenFOAM: ondas de choque y de expansión cuya teoría se conoce, de modo que cada caso se puede comprobar cifra por cifra. Cada tutorial trae el caso completo, la malla de Gmsh y una validación contra la teoría con un estudio de convergencia de malla.
