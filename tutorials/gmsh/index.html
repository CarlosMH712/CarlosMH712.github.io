Software tutorials · Gmsh

Gmsh

A tutorial series on mesh generation with Gmsh for simulation: from a 2.5D mesh for OpenFOAM, through three-dimensional meshes for fluids, to meshes for solid mechanics in CalculiX. The main thread is fluid dynamics, but nothing is restricted to aerodynamics.

Two paths, one file. Every tutorial is taught twice: with the graphical interface, to see what happens, and by writing the .geo file, to parametrise and repeat. Every figure and number comes from an actual run of Gmsh 4.15.2 and, where a solver is involved, of OpenFOAM 13.

Tutoriales de software · Gmsh

Gmsh

Una serie sobre generación de mallas con Gmsh para simulación: de la malla 2.5D para OpenFOAM, pasando por mallas tridimensionales para fluidos, hasta mallas para mecánica de sólidos en CalculiX. El hilo conductor es la dinámica de fluidos, pero nada se limita a la aerodinámica.

Dos caminos, un solo archivo. Cada tutorial se enseña dos veces: con la interfaz gráfica, para ver qué ocurre, y escribiendo el archivo .geo, para parametrizar y repetir. Todas las figuras y cifras proceden de corridas reales de Gmsh 4.15.2 y, cuando interviene un solver, de OpenFOAM 13.

Software-Tutorials · Gmsh

Gmsh

Eine Reihe zur Netzerzeugung mit Gmsh für die Simulation: vom 2,5D-Netz für OpenFOAM über dreidimensionale Netze für Strömungen bis zu Netzen für die Festkörpermechanik in CalculiX. Der rote Faden ist die Strömungsmechanik, doch nichts ist auf Aerodynamik beschränkt.

Zwei Wege, eine Datei. Jedes Tutorial wird zweimal gezeigt: über die grafische Oberfläche, um zu sehen, was geschieht, und durch Schreiben der .geo-Datei, um zu parametrisieren und zu wiederholen. Alle Abbildungen und Zahlen stammen aus tatsächlichen Läufen von Gmsh 4.15.2 und, wo ein Löser beteiligt ist, von OpenFOAM 13.
