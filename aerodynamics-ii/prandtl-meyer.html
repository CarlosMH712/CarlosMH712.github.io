Physical picture

A convex corner creates a continuous expansion fan

When a supersonic stream turns away from itself, the pressure adjustment cannot occur through an expansion shock. Instead, a continuous family of Mach waves forms a centered Prandtl–Meyer fan.

Expansion behavior. Mach number increases, while static pressure, temperature, and density decrease. Total temperature and total pressure remain constant.

Differential relation

An infinitesimal turn through a Mach wave

For an infinitesimal expansion \(d\theta\), velocity and Mach satisfy

\[ \boxed{ d\theta = \sqrt{M^2-1}\frac{dV}{V} } \]
\[ \boxed{ d\theta= \frac{\sqrt{M^2-1}} {1+\frac{\gamma-1}{2}M^2} \frac{dM}{M} } \]

This differential relation is integrated from the sonic state to define the Prandtl–Meyer function.

Central function

The Prandtl–Meyer function

\[ \boxed{ \nu(M)= \sqrt{\frac{\gamma+1}{\gamma-1}} \tan^{-1}\left[ \sqrt{\frac{\gamma-1}{\gamma+1}(M^2-1)} \right] - \tan^{-1}\left(\sqrt{M^2-1}\right) } \]

The function measures the isentropic turning accumulated from \(M=1\), where \(\nu(1)=0\), to the specified Mach number.

\[ \boxed{ \nu_{\max} = \frac{\pi}{2} \left( \sqrt{\frac{\gamma+1}{\gamma-1}}-1 \right) } \]

For air, \(\nu_{\max}=130.45^\circ\).

Finite turn

A centered fan connects two uniform supersonic states

\[ \boxed{ \theta=\nu(M_2)-\nu(M_1) } \]

For a known upstream state and turn angle,

\[ \boxed{ \nu(M_2)=\nu(M_1)+\theta } \]

The inverse problem \(M=\nu^{-1}(\nu)\) has no simple elementary closed form, so it is solved using a table or a numerical root finder.

First characteristic\(\mu_1=\sin^{-1}(1/M_1)\)
Last characteristic\(\mu_2=\sin^{-1}(1/M_2)\)

Isentropic property changes

Pressure, temperature, and density ratios

\[ \boxed{ \frac{T_2}{T_1} = \frac{1+\frac{\gamma-1}{2}M_1^2} {1+\frac{\gamma-1}{2}M_2^2} } \]
\[ \boxed{ \frac{p_2}{p_1} = \left(\frac{T_2}{T_1}\right)^{\gamma/(\gamma-1)} } \]
\[ \boxed{ \frac{\rho_2}{\rho_1} = \left(\frac{T_2}{T_1}\right)^{1/(\gamma-1)} } \]
\[ \boxed{ T_{0,2}=T_{0,1}, \qquad p_{0,2}=p_{0,1} } \]

Engineering workflow

Calculation algorithm

1Specify \(M_1,\theta,\gamma\)
2Compute \(\nu_1=\nu(M_1)\)
3Set \(\nu_2=\nu_1+\theta\)
4Check \(\nu_2<\nu_{\max}\)
5Solve \(\nu(M_2)=\nu_2\)
6Compute \(T_2/T_1\)
7Compute \(p_2/p_1,\rho_2/\rho_1\)
8Verify \(M_2>M_1\) and \(p_{0,2}=p_{0,1}\)

Worked example

A \(15^\circ\) expansion from \(M_1=2\)

Air at \(M_1=2.0\), \(p_1=120\ \text{kPa}\), and \(T_1=300\ \text{K}\) expands through \(\theta=15^\circ\).

1
\[\nu(M_1)=26.38^\circ.\]
2
\[\nu(M_2)=26.38^\circ+15^\circ=41.38^\circ.\]
3
\[M_2\approx2.59845.\]
4
\[\frac{T_2}{T_1}=0.76583,\qquad T_2\approx229.7\ \text{K}.\]
5
\[\frac{p_2}{p_1}=0.39307,\qquad p_2\approx47.2\ \text{kPa}.\]
\[ \boxed{ M_2\approx2.598,\quad T_2\approx229.7\ \text{K},\quad p_2\approx47.2\ \text{kPa} } \]

Interpretación física

Una esquina convexa genera un abanico continuo

Al girar alejándose de sí misma, una corriente supersónica se expande mediante una familia continua de ondas de Mach, no mediante un choque expansivo.

El Mach aumenta; presión, temperatura y densidad estáticas disminuyen; \(T_0\) y \(p_0\) permanecen constantes.

Relación diferencial

Expansión infinitesimal

\[\boxed{d\theta=\sqrt{M^2-1}\frac{dV}{V}}\]
\[\boxed{d\theta=\frac{\sqrt{M^2-1}}{1+\frac{\gamma-1}{2}M^2}\frac{dM}{M}}\]

Función central

Función de Prandtl–Meyer

\[ \boxed{ \nu(M)= \sqrt{\frac{\gamma+1}{\gamma-1}} \tan^{-1}\left[\sqrt{\frac{\gamma-1}{\gamma+1}(M^2-1)}\right] - \tan^{-1}\left(\sqrt{M^2-1}\right) } \]

Para aire, \(\nu_{\max}=130.45^\circ\).

Giro finito

Abanico centrado

\[\boxed{\theta=\nu(M_2)-\nu(M_1)}\]
\[\boxed{\nu(M_2)=\nu(M_1)+\theta}\]

La inversión de \(\nu(M)\) requiere tablas o un algoritmo numérico.

Cambios isoentrópicos

Relaciones de propiedades

\[\boxed{\frac{T_2}{T_1}=\frac{1+\frac{\gamma-1}{2}M_1^2}{1+\frac{\gamma-1}{2}M_2^2}}\]
\[\boxed{\frac{p_2}{p_1}=\left(\frac{T_2}{T_1}\right)^{\gamma/(\gamma-1)}}\]
\[\boxed{\frac{\rho_2}{\rho_1}=\left(\frac{T_2}{T_1}\right)^{1/(\gamma-1)}}\]
\[\boxed{T_{0,2}=T_{0,1},\qquad p_{0,2}=p_{0,1}}\]

Procedimiento

Algoritmo de cálculo

  1. Calcular \(\nu_1=\nu(M_1)\).
  2. Formar \(\nu_2=\nu_1+\theta\).
  3. Verificar \(\nu_2<\nu_{\max}\).
  4. Resolver \(\nu(M_2)=\nu_2\).
  5. Calcular las razones de propiedades.
  6. Comprobar \(M_2>M_1\) y conservación de \(p_0\).

Kerninhalt

Prandtl–Meyer-Expansion

Eine konvexe Ecke erzeugt einen kontinuierlichen isentropen Expansionsfächer.

\[\boxed{\theta=\nu(M_2)-\nu(M_1)}\]
\[\boxed{\nu(M)=\sqrt{\frac{\gamma+1}{\gamma-1}}\tan^{-1}\sqrt{\frac{\gamma-1}{\gamma+1}(M^2-1)}-\tan^{-1}\sqrt{M^2-1}}\]
Die Machzahl steigt; statischer Druck und Temperatur sinken; der Totaldruck bleibt konstant.
