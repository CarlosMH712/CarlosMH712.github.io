Learning objectives

What you should be able to do

  • Explain why a convex turn produces a continuous fan rather than an expansion shock.
  • Evaluate the Prandtl–Meyer function \(\nu(M)\).
  • Solve \(\nu(M_2)=\nu(M_1)+\theta\) for the downstream Mach number.
  • Compute the isentropic property ratios across a centred fan.
  • Recognise the \(\nu_{\max}\) ceiling and say what it means physically.

Physical picture

A convex corner creates a continuous expansion fan

When a supersonic stream turns away from itself, the pressure adjustment cannot occur through an expansion shock. Instead, a continuous family of Mach waves forms a centered Prandtl–Meyer fan.

Expansion behavior. Mach number increases, while static pressure, temperature, and density decrease. Total temperature and total pressure remain constant.

Model and assumptions

An isentropic turn with no length scale

  • steady, inviscid, two-dimensional flow of a calorically perfect gas;
  • supersonic flow turning away from itself around a convex corner;
  • isentropic throughout, so \(p_0\) and \(T_0\) are both conserved;
  • a centred fan, with all Mach waves emanating from the corner.
Not included. A real corner has a finite radius, so the fan is not exactly centred and the waves do not all originate from one point. The model also ignores the boundary layer, which near the wall smears the first characteristics. Neither affects the far-field turn angle appreciably, which is why the idealisation survives.

Differential relation

An infinitesimal turn through a Mach wave

For an infinitesimal expansion \(d\theta\), velocity and Mach satisfy

\[ \boxed{ d\theta = \sqrt{M^2-1}\frac{dV}{V} } \]
\[ \boxed{ d\theta= \frac{\sqrt{M^2-1}} {1+\frac{\gamma-1}{2}M^2} \frac{dM}{M} } \]

This differential relation is integrated from the sonic state to define the Prandtl–Meyer function.

Central function

The Prandtl–Meyer function

\[ \boxed{ \nu(M)= \sqrt{\frac{\gamma+1}{\gamma-1}} \tan^{-1}\left[ \sqrt{\frac{\gamma-1}{\gamma+1}(M^2-1)} \right] - \tan^{-1}\left(\sqrt{M^2-1}\right) } \]

The function measures the isentropic turning accumulated from \(M=1\), where \(\nu(1)=0\), to the specified Mach number.

\[ \boxed{ \nu_{\max} = \frac{\pi}{2} \left( \sqrt{\frac{\gamma+1}{\gamma-1}}-1 \right) } \]

For air, \(\nu_{\max}=130.45^\circ\).

Finite turn

A centered fan connects two uniform supersonic states

\[ \boxed{ \theta=\nu(M_2)-\nu(M_1) } \]

For a known upstream state and turn angle,

\[ \boxed{ \nu(M_2)=\nu(M_1)+\theta } \]

The inverse problem \(M=\nu^{-1}(\nu)\) has no simple elementary closed form, so it is solved using a table or a numerical root finder.

First characteristic\(\mu_1=\sin^{-1}(1/M_1)\)
Last characteristic\(\mu_2=\sin^{-1}(1/M_2)\)

Isentropic property changes

Pressure, temperature, and density ratios

\[ \boxed{ \frac{T_2}{T_1} = \frac{1+\frac{\gamma-1}{2}M_1^2} {1+\frac{\gamma-1}{2}M_2^2} } \]
\[ \boxed{ \frac{p_2}{p_1} = \left(\frac{T_2}{T_1}\right)^{\gamma/(\gamma-1)} } \]
\[ \boxed{ \frac{\rho_2}{\rho_1} = \left(\frac{T_2}{T_1}\right)^{1/(\gamma-1)} } \]
\[ \boxed{ T_{0,2}=T_{0,1}, \qquad p_{0,2}=p_{0,1} } \]

Calculation algorithm

Calculation algorithm

1Specify \(M_1,\theta,\gamma\)
2Compute \(\nu_1=\nu(M_1)\)
3Set \(\nu_2=\nu_1+\theta\)
4Check \(\nu_2<\nu_{\max}\)
5Solve \(\nu(M_2)=\nu_2\)
6Compute \(T_2/T_1\)
7Compute \(p_2/p_1,\rho_2/\rho_1\)
8Verify \(M_2>M_1\) and \(p_{0,2}=p_{0,1}\)

Common mistakes

Common mistakes

  • Applying \(\nu(M)\) to a compression. The Prandtl–Meyer function describes isentropic expansions only; a concave turn produces an oblique shock and is handled with θ–β–M.
  • Believing an expansion lowers total pressure. In the ideal model the fan is isentropic, so \(p_{0}\) is conserved. Only the static properties fall.
  • Reading \(\nu\) as a Mach number. \(\nu\) is an accumulated turning angle measured from \(M=1\); it is not itself a Mach number and has units of degrees.
  • Adding \(\theta\) to \(M\) instead of to \(\nu\). The turn angle adds to the Prandtl–Meyer function, not to the Mach number: \(\nu(M_2)=\nu(M_1)+\theta\).
  • Ignoring the \(\nu_{\max}\) ceiling. If \(\nu(M_1)+\theta\) exceeds \(130.45^\circ\) for air, the requested turn is impossible: the gas would need to expand to zero pressure, and a vacuum region forms instead.
  • Expecting \(\nu_{\max}\) to be reachable in practice. It corresponds to \(M\to\infty\) with \(p\to0\), where the calorically perfect model has long since stopped applying.
  • Using an expansion shock. There is no such thing: it would decrease entropy and the second law forbids it.

Panorama físico

Una esquina convexa genera un abanico de expansión continuo

Cuando una corriente supersónica gira alejándose de sí misma, el ajuste de presión no puede ocurrir mediante un choque de expansión. En su lugar, una familia continua de ondas de Mach forma un abanico centrado de Prandtl–Meyer.

Comportamiento de la expansión. El número de Mach aumenta, mientras que la presión, la temperatura y la densidad estáticas disminuyen. La temperatura total y la presión total permanecen constantes.

Modelo e hipótesis

Un viraje isoentrópico sin escala de longitud

  • flujo estacionario, inviscido y bidimensional de un gas calóricamente perfecto;
  • flujo supersónico que gira alejándose de sí mismo en una esquina convexa;
  • isoentrópico en todo el proceso, de modo que \(p_0\) y \(T_0\) se conservan;
  • abanico centrado, con todas las ondas de Mach emanando de la esquina.
No incluido. Una esquina real tiene radio finito, así que el abanico no está exactamente centrado y las ondas no salen todas de un punto. El modelo también ignora la capa límite, que cerca de la pared difumina las primeras características. Ninguna de las dos afecta apreciablemente al ángulo de giro en campo lejano, y por eso la idealización sobrevive.

Relación diferencial

Un viraje infinitesimal a través de una onda de Mach

Para una expansión infinitesimal \(d\theta\), la velocidad y el Mach satisfacen

\[ \boxed{ d\theta = \sqrt{M^2-1}\frac{dV}{V} } \]
\[ \boxed{ d\theta= \frac{\sqrt{M^2-1}} {1+\frac{\gamma-1}{2}M^2} \frac{dM}{M} } \]

Esta relación diferencial se integra desde el estado sónico para definir la función de Prandtl–Meyer.

Función central

La función de Prandtl–Meyer

\[ \boxed{ \nu(M)= \sqrt{\frac{\gamma+1}{\gamma-1}} \tan^{-1}\left[ \sqrt{\frac{\gamma-1}{\gamma+1}(M^2-1)} \right] - \tan^{-1}\left(\sqrt{M^2-1}\right) } \]

La función mide el viraje isoentrópico acumulado desde \(M=1\), donde \(\nu(1)=0\), hasta el número de Mach especificado.

\[ \boxed{ \nu_{\max} = \frac{\pi}{2} \left( \sqrt{\frac{\gamma+1}{\gamma-1}}-1 \right) } \]

Para aire, \(\nu_{\max}=130.45^\circ\).

Viraje finito

Un abanico centrado conecta dos estados supersónicos uniformes

\[ \boxed{ \theta=\nu(M_2)-\nu(M_1) } \]

Para un estado aguas arriba conocido y un ángulo de viraje dado,

\[ \boxed{ \nu(M_2)=\nu(M_1)+\theta } \]

El problema inverso \(M=\nu^{-1}(\nu)\) no tiene una forma cerrada elemental sencilla, de modo que se resuelve con tabla o con un buscador numérico de raíces.

Primera característica\(\mu_1=\sin^{-1}(1/M_1)\)
Última característica\(\mu_2=\sin^{-1}(1/M_2)\)

Cambios isoentrópicos de propiedades

Razones de presión, temperatura y densidad

\[ \boxed{ \frac{T_2}{T_1} = \frac{1+\frac{\gamma-1}{2}M_1^2} {1+\frac{\gamma-1}{2}M_2^2} } \]
\[ \boxed{ \frac{p_2}{p_1} = \left(\frac{T_2}{T_1}\right)^{\gamma/(\gamma-1)} } \]
\[ \boxed{ \frac{\rho_2}{\rho_1} = \left(\frac{T_2}{T_1}\right)^{1/(\gamma-1)} } \]
\[ \boxed{ T_{0,2}=T_{0,1}, \qquad p_{0,2}=p_{0,1} } \]

Errores comunes

Errores comunes

  • Aplicar \(\nu(M)\) a una compresión. La función de Prandtl–Meyer describe solo expansiones isoentrópicas; un viraje cóncavo produce un choque oblicuo y se trata con θ–β–M.
  • Creer que una expansión baja la presión total. En el modelo ideal el abanico es isoentrópico, así que \(p_{0}\) se conserva. Solo caen las propiedades estáticas.
  • Leer \(\nu\) como un número de Mach. \(\nu\) es un ángulo de viraje acumulado medido desde \(M=1\); no es un Mach y tiene unidades de grados.
  • Sumar \(\theta\) a \(M\) en lugar de a \(\nu\). El ángulo de viraje se suma a la función de Prandtl–Meyer, no al número de Mach: \(\nu(M_2)=\nu(M_1)+\theta\).
  • Ignorar el techo \(\nu_{\max}\). Si \(\nu(M_1)+\theta\) supera los \(130.45^\circ\) para aire, el viraje pedido es imposible: el gas tendría que expandirse a presión cero, y en su lugar se forma una región de vacío.
  • Esperar que \(\nu_{\max}\) sea alcanzable en la práctica. Corresponde a \(M\to\infty\) con \(p\to0\), donde el modelo calóricamente perfecto dejó de aplicar hace mucho.
  • Usar un choque de expansión. No existe: disminuiría la entropía y la segunda ley lo prohíbe.

Lernziele

Was Sie danach können sollten

  • Erläutern, warum eine konvexe Umlenkung einen stetigen Fächer und keinen Expansionsstoß erzeugt.
  • Die Prandtl–Meyer-Funktion \(\nu(M)\) auswerten.
  • \(\nu(M_2)=\nu(M_1)+\theta\) nach der stromabwärtigen Machzahl lösen.
  • Die isentropen Zustandsverhältnisse über einen zentrierten Fächer berechnen.
  • Die Schranke \(\nu_{\max}\) erkennen und ihre physikalische Bedeutung angeben.

Physikalisches Bild

Eine konvexe Ecke erzeugt einen kontinuierlichen Expansionsfächer

Wenn eine Überschallströmung von sich weg umgelenkt wird, kann der Druckausgleich nicht über einen Expansionsstoß erfolgen. Stattdessen bildet eine kontinuierliche Schar von Machwellen einen zentrierten Prandtl–Meyer-Fächer.

Verhalten der Expansion. Die Machzahl nimmt zu, während statischer Druck, Temperatur und Dichte abnehmen. Totaltemperatur und Totaldruck bleiben konstant.

Modell und Annahmen

Eine isentrope Umlenkung ohne Längenmaßstab

  • stationäre, reibungsfreie, zweidimensionale Strömung eines kalorisch idealen Gases;
  • überschallschnelle Strömung, die an einer konvexen Ecke von sich weg umgelenkt wird;
  • durchgehend isentrop, sodass \(p_0\) und \(T_0\) erhalten bleiben;
  • zentrierter Fächer, dessen Machwellen sämtlich von der Ecke ausgehen.
Nicht enthalten. Eine reale Ecke besitzt einen endlichen Radius, sodass der Fächer nicht exakt zentriert ist und die Wellen nicht alle aus einem Punkt entspringen. Das Modell vernachlässigt zudem die Grenzschicht, die wandnah die ersten Charakteristiken verschmiert. Beides beeinflusst den Umlenkwinkel im Fernfeld kaum — deshalb hält die Idealisierung stand.

Differentielle Beziehung

Eine infinitesimale Umlenkung über eine Machwelle

Für eine infinitesimale Expansion \(d\theta\) erfüllen Geschwindigkeit und Machzahl

\[ \boxed{ d\theta = \sqrt{M^2-1}\frac{dV}{V} } \]
\[ \boxed{ d\theta= \frac{\sqrt{M^2-1}} {1+\frac{\gamma-1}{2}M^2} \frac{dM}{M} } \]

Diese differentielle Beziehung wird vom Schallzustand aus integriert und definiert damit die Prandtl–Meyer-Funktion.

Zentrale Funktion

Die Prandtl–Meyer-Funktion

\[ \boxed{ \nu(M)= \sqrt{\frac{\gamma+1}{\gamma-1}} \tan^{-1}\left[ \sqrt{\frac{\gamma-1}{\gamma+1}(M^2-1)} \right] - \tan^{-1}\left(\sqrt{M^2-1}\right) } \]

Die Funktion misst die vom Zustand \(M=1\) mit \(\nu(1)=0\) an aufsummierte isentrope Umlenkung bis zur angegebenen Machzahl.

\[ \boxed{ \nu_{\max} = \frac{\pi}{2} \left( \sqrt{\frac{\gamma+1}{\gamma-1}}-1 \right) } \]

Für Luft ist \(\nu_{\max}=130{,}45^\circ\).

Endliche Umlenkung

Ein zentrierter Fächer verbindet zwei gleichförmige Überschallzustände

\[ \boxed{ \theta=\nu(M_2)-\nu(M_1) } \]

Bei bekanntem Zustand stromauf und gegebenem Umlenkwinkel gilt

\[ \boxed{ \nu(M_2)=\nu(M_1)+\theta } \]

Das inverse Problem \(M=\nu^{-1}(\nu)\) besitzt keine einfache elementare geschlossene Form und wird daher mit einer Tabelle oder einem numerischen Nullstellenverfahren gelöst.

Erste Charakteristik\(\mu_1=\sin^{-1}(1/M_1)\)
Letzte Charakteristik\(\mu_2=\sin^{-1}(1/M_2)\)

Isentrope Zustandsänderungen

Druck-, Temperatur- und Dichteverhältnisse

\[ \boxed{ \frac{T_2}{T_1} = \frac{1+\frac{\gamma-1}{2}M_1^2} {1+\frac{\gamma-1}{2}M_2^2} } \]
\[ \boxed{ \frac{p_2}{p_1} = \left(\frac{T_2}{T_1}\right)^{\gamma/(\gamma-1)} } \]
\[ \boxed{ \frac{\rho_2}{\rho_1} = \left(\frac{T_2}{T_1}\right)^{1/(\gamma-1)} } \]
\[ \boxed{ T_{0,2}=T_{0,1}, \qquad p_{0,2}=p_{0,1} } \]

Auf einen Blick

Häufige Fehler

Häufige Fehler

  • \(\nu(M)\) auf eine Verdichtung anwenden. Die Prandtl–Meyer-Funktion beschreibt ausschließlich isentrope Expansionen; eine konkave Umlenkung erzeugt einen schrägen Stoß und wird mit θ–β–M behandelt.
  • Glauben, eine Expansion senke den Totaldruck. Im idealen Modell ist der Fächer isentrop, \(p_{0}\) bleibt also erhalten. Nur die statischen Größen sinken.
  • \(\nu\) als Machzahl lesen. \(\nu\) ist ein von \(M=1\) an aufsummierter Umlenkwinkel; es ist selbst keine Machzahl und wird in Grad angegeben.
  • \(\theta\) zu \(M\) statt zu \(\nu\) addieren. Der Umlenkwinkel addiert sich zur Prandtl–Meyer-Funktion, nicht zur Machzahl: \(\nu(M_2)=\nu(M_1)+\theta\).
  • Die Schranke \(\nu_{\max}\) übergehen. Überschreitet \(\nu(M_1)+\theta\) für Luft \(130{,}45^\circ\), ist die verlangte Umlenkung unmöglich: das Gas müsste auf Druck null expandieren, und es bildet sich stattdessen ein Vakuumgebiet.
  • Erwarten, dass \(\nu_{\max}\) praktisch erreichbar ist. Es entspricht \(M\to\infty\) mit \(p\to0\), wo das kalorisch ideale Modell längst nicht mehr gilt.
  • Einen Expansionsstoß verwenden. Einen solchen gibt es nicht: er würde die Entropie verringern, was der zweite Hauptsatz verbietet.

Rechenwerkzeug

Rechner öffnen

Das Expansionsmodul invertiert \(\nu(M)\) numerisch und meldet eine geforderte Umlenkung, die \(\nu_{\max}\) überschreiten würde. Zusammen mit dem Schrägstoß-Modul bildet es den sequenziellen Löser aus Vorlesung 06.
